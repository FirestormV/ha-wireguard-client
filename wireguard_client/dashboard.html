Setup and public key help

Copy the client public key to its peer in pfSense. Complete Configuration, save and restart. Leave Client private key empty to reuse the saved identity. The tunnel does not need a handshake to display its public key.

Configuration stays in Home Assistant add-on options. No settings can be changed on this page.
